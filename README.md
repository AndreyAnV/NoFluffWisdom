# NoFluffWisdom (v2)

> **An Operating System for Better Thinking**  
> A disciplined system for clearer thinking, built for people who are done consuming noise.

---

## ✦ Overview

**NoFluffWisdom** is a landing page built around depth, discipline, and high-signal insights. Designed with modern web standards, editorial typography, and subtle micro-interactions, it presents frameworks, rituals, and field notes without feed clutter or promotional distraction.

---

## ✦ Key Features

- **Cinematic Background Engine**: Seamless video loop crossfading with subtle particle orbs and film grain overlays.
- **Curated Content Shelf**: Visual presentation of flagship frameworks (*The Focus Protocol*, *Thinking in Systems*, *The Discipline Playbook*, *Books Worth Finishing*).
- **Interactive Glassmorphism**: Custom mouse-reactive cards (`data-glass`) with dynamic lighting shifts and responsive elevation hover effects.
- **Smart Adaptive Navigation**: Context-aware top navbar that auto-hides during reading and dynamically shifts contrast over dark and light section bands.
- **Subscription Flow & Modal**: Smooth multi-step email reveal interaction paired with a frosted glass confirmation modal.
- **Mobile-First & Accessible**: Fully responsive grid layouts, semantic HTML5 structure, and screen-reader accessible attributes.

---

## ✦ Tech Stack

- **HTML5**: Semantic markup with full accessibility metadata.
- **CSS3**: Custom design tokens, CSS Grid & Flexbox, hardware-accelerated animations, and responsive media queries.
- **JavaScript**: ES6+ modules for scroll-progress tracking, IntersectionObservers, mouse position calculations, and video crossfading.
